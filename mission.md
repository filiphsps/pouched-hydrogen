# Agent Mission

**Objective:** Build a B2C Shopify Hydrogen Storefront selling Swedish tobacco-free snus (all-white snus) to the German market.

## Description

We're building a direct to consumer e-commerce store named "Pouched" selling Swedish tobacco-free snus (all-white snus) to the German market. The store will be built using Shopify Hydrogen with the `@weaverse/pilot` template as a starting point. Our prinary goal is to build a storefront that ranks the highest possible in Google and other search engines while also being the best experience possible for the customer.

## Success Criteria
- ALL Shopify hydrogen routes are implemented.
- The components are modular and reusable.
- Common code is extracted into shared utilities, hooks, etc.
- Theming is completely user-configurable and not hardcoded.
- There are tests for every component, route, utility function, etc.
- Using i18n for ALL text content.
- We visualize quantity-based discounts in the relevant places if it's used for the product.
- We have integrated/support the most common Shopify Apps:
  - Judge.me Product Reviews App.
  - Shopify Bundles.
  - Shopify Subscriptions, Recharge Subscriptions.
  - Aco Custom Discounts (for quantity-based discounts).
- We have ALL sitemap routes implemented.
- We have a wishlist feature with sharing implemented.
- Search supports filtering and real-time suggestions.
- We have product recommendation components implemented and used.
- The UI is responsive, mobile-first, and extremely well designed.
- The UX is intuitive and easy to navigate, with accessible design principles.
- Every route is FULLY SEO optimized.
- Every route has a high Lighthouse score.
